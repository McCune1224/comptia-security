# Common Security+ Acronyms

## Domain 1 - General Security Concepts
| Acronym | Full Name | Definition |
|---------|-----------|------------|
| CIA | Confidentiality, Integrity, Availability | Core security principles |
| AAA | Authentication, Authorization, Accounting | Security framework |
| ACL | Access Control List | List of permissions |
| RBAC | Role-Based Access Control | Access based on roles |
| ABAC | Attribute-Based Access Control | Access based on attributes |
| SSO | Single Sign-On | One login for multiple systems |
| MFA | Multi-Factor Authentication | Multiple verification methods |

## Domain 2 - Threats & Vulnerabilities
| Acronym | Full Name | Definition |
|---------|-----------|------------|
| APT | Advanced Persistent Threat | Long-term targeted attack |
| DDoS | Distributed Denial of Service | Overwhelming traffic attack |
| MITM | Man-in-the-Middle | Intercepting communication |
| XSS | Cross-Site Scripting | Injecting malicious scripts |
| SQLi | SQL Injection | Database manipulation |
| CSRF | Cross-Site Request Forgery | Unauthorized commands |

| Acronym | Full Name | Definition |

| IPS | Intrusion Prevention System | Active threat blocking |
| IDS | Intrusion Detection System | Passive threat monitoring |
| WAF | Web Application Firewall | Application layer protection |
| CASB | Cloud Access Security Broker | Cloud security gateway |
