# PBQ (Performance-Based Questions) Practice

## What are PBQs?
- Drag-and-drop questions
- Configuration simulations
- Scenario-based troubleshooting
- Usually 3-5 questions on the exam

## Common PBQ Topics
1. **Firewall rule configuration**
2. **Certificate management**
3. **Log analysis**
4. **Network troubleshooting**
5. **Access control configuration**

## How to Practice
1. Use practice exam PBQs (LogN Pacific, FlashGenius)
2. Set up virtual labs for hands-on practice
3. Time yourself - PBQs take longer than multiple choice
4. Read carefully - some PBQs have multiple correct answers

## File Organization
Create one file per PBQ type:
- `Firewall-PBQ-Practice.md`
- `Certificate-PBQ-Practice.md`
- `Log-Analysis-PBQ.md`

## PBQ Strategy
1. **Skip if stuck** - Come back later (PBQs are time-consuming)
2. **Read all options** before answering
3. **Check your work** - Verify configurations
4. **Don't overthink** - Usually straightforward if you know the concept
