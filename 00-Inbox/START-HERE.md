# Getting Started with Your Security+ Vault

Welcome! This vault is organized to help you efficiently study for the CompTIA Security+ SY0-701 exam.

## 🗺️ Vault Structure

```
📁 00-Inbox/          → Quick capture for temporary notes
📁 01-Index/          → Dashboard and trackers (START HERE!)
📁 02-Domains/        → Your main study notes by domain
📁 03-Flashcards/     → Anki-ready flashcards
📁 04-Resources/      → Video notes, practice test logs
📁 05-Exam-Prep/      → PBQs and mock exams
📁 99-Archive/        → Completed/old notes
```

## 🚀 Quick Start

1. **Open [[Security+ Dashboard]]** - Your central hub
2. **Review [[Objectives]]** - Your cram plan
3. **Start with Domain 1** - Follow the folder structure
4. **Create flashcards** as you go - Use templates

## 📋 Templates Available

- **Domain-Note** - For concept notes
- **Flashcard** - For Q&A format cards
- **Acronym** - For abbreviation definitions

*Access via: Ctrl+P → "Templates: Insert Template"*

## 🏷️ Tags to Use

- `#flashcard` - For all flashcards
- `#acronym` - For abbreviations
- `#domain-01` through `#domain-05` - Domain tags
- `#weak-topic` - For areas needing review

## 📊 Track Your Progress

Update these files weekly:
- [[Security+ Dashboard]] - Overall progress
- [[Weak Topics Tracker]] - Areas to improve
- [[Exam Checklist]] - Exam preparation

## 💡 Tips

1. **Take notes daily** using the Domain-Note template
2. **Create flashcards immediately** when you learn new terms
3. **Review weak topics** before each study session
4. **Practice tests weekly** and update your tracker
5. **Use Obsidian's graph view** to see connections between concepts
