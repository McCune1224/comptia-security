## Week 1 – Domains 1 & 2 (Foundations + Threats)

### Week 1 – General Goals

- [ ] Cover all of Domain 1: General Security Concepts.
- [ ] Cover all of Domain 2: Threats, Vulnerabilities, and Mitigations.
- [ ] Complete at least one mixed Domain 1+2 mini‑test by end of week.

---

### Week 1 – Mon–Tue (Domain 1.0 – General Security Concepts)

Focus: CIA, AAA, control types, Zero Trust, physical security, crypto basics, change management.

#### Tasks

- [ ] Read Cert Guide sections/chapters mapped to Domain 1.0:
  - CIA, AAA, security controls, Zero Trust, physical security, deception tech, change management.
- [ ] Watch Messer videos for:
  - [ ] CIA, non‑repudiation, AAA basics.
  - [ ] Security control categories and types.
  - [ ] Zero Trust architecture (control plane / data plane).
  - [ ] Physical security and deception tech.
  - [ ] Change management and documentation basics.
- [ ] Create quick notes:
  - [ ] Definitions for each control type (preventive, detective, corrective, compensating, deterrent, directive).
  - [ ] One‑sentence summary for Zero Trust and its key components.
- [ ] Questions:
  - [ ] Do 30–40 Domain 1‑focused questions (LogN Pacific / FlashGenius).
  - [ ] Flag any concept missed more than once for review.

---

### Week 1 – Wed–Sun (Domain 2.0 – Threats, Vulnerabilities, Mitigations)

Focus: threat actors/motivations, vectors, malware, attacks, vulnerabilities, mitigation techniques.

#### Tasks

- [ ] Read Cert Guide chapters mapped to Domain 2.0:
  - [ ] Threat actors and attributes.
  - [ ] Threat vectors (email, web, removable, social engineering).
  - [ ] Malware types (ransomware, trojans, worms, spyware, rootkits, etc.).
  - [ ] Network, app, crypto, and physical attacks.
  - [ ] Common vulnerabilities (app, OS, web, cloud, supply chain, mobile, misconfig).
  - [ ] Mitigation techniques (segmentation, hardening, patching, least privilege).
- [ ] Watch Messer videos for:
  - [ ] Threat actors and motivations.
  - [ ] Social engineering and message‑based vectors.
  - [ ] Malware and payload types.
  - [ ] Network and application attacks.
  - [ ] Indicators of compromise and basic mitigations.
- [ ] Questions (each day Wed–Sun):
  - [ ] 40–60 Domain 2‑focused questions (LogN Pacific / FlashGenius).
  - [ ] Track weak areas (e.g., SQLi vs XSS vs CSRF, DDoS variants, password / crypto attacks).
- [ ] Weekend checkpoint:
  - [ ] Take a Domain 1+2 mini‑test (from LogN Pacific or FlashGenius).
  - [ ] Review all missed questions and map each one back to the corresponding objective in the PDF.

#### Optional Lab (Weekend)

- [ ] Spin up a small lab (e.g., Kali + Windows VM).
- [ ] Run a vulnerability scan and review findings.
- [ ] Generate and inspect basic logs for later Domain 4 practice.

---

## Week 2 – Domains 3 & 4 (Architecture + Operations)

### Week 2 – General Goals

- [ ] Cover all of Domain 3: Security Architecture.
- [ ] Cover at least half of Domain 4: Security Operations.
- [ ] Take one full 90‑question timed practice exam by the end of the week.

---

### Week 2 – Mon–Wed (Domain 3.0 – Security Architecture)

Focus: cloud/on‑prem, segmentation, virtualization, ICS/SCADA, data protection, HA and recovery.

#### Tasks

- [ ] Read Cert Guide chapters for Domain 3.0:
  - [ ] Architecture models (cloud, hybrid, IaC, serverless, microservices).
  - [ ] Network infrastructure and segmentation (air‑gap, VLANs, SDN).
  - [ ] Containerization/virtualization, IoT, ICS/SCADA, embedded/RTOS.
  - [ ] Data types/classifications and protection methods.
  - [ ] Resilience, high availability, backup sites, backups/replication.
- [ ] Watch Messer Domain 3 videos:
  - [ ] Cloud models and shared responsibility.
  - [ ] Segmentation and secure network design.
  - [ ] Data protection techniques (encryption, masking, tokenization, ACLs).
  - [ ] HA, DR, and continuity of operations.
- [ ] Questions:
  - [ ] 40+ Domain 3 questions per day (LogN Pacific / FlashGenius).
  - [ ] Note scenario questions where the wrong design is chosen and why.

---

### Week 2 – Thu–Sun (Start Domain 4.0 – Security Operations)

Focus: baselines/hardening, endpoints, mobile/wireless, monitoring, vuln mgmt, automation, IR.

#### Tasks

- [ ] Read Cert Guide chapters mapped to early Domain 4.0:
  - [ ] Secure baselines and hardening for servers, workstations, network devices, and cloud.
  - [ ] Mobile and wireless security (MDM, BYOD/COPE/CYOD, WPA3, RADIUS).
  - [ ] Application security basics (input validation, secure cookies, code signing).
  - [ ] Monitoring and logging, SIEM, vulnerability management lifecycle.
  - [ ] Intro to automation/orchestration and scripting use cases.
- [ ] Watch Messer Domain 4 videos:
  - [ ] Baselines, hardening, endpoint security.
  - [ ] Wireless and mobile security.
  - [ ] Monitoring and logging, SIEM basics.
  - [ ] Vulnerability management and remediation.
  - [ ] Intro automation/orchestration and IR lifecycle.
- [ ] Questions (each day Thu–Sun):
  - [ ] 40–60 Domain 4‑focused questions.
  - [ ] Add 10–15 mixed review questions from Domains 1–3.
- [ ] Full exam (by Sun):
  - [ ] Take one full 90‑question timed practice exam (LogN Pacific or FlashGenius).
  - [ ] Record score and domain breakdown.
  - [ ] List top 3 weakest domains and specific objectives to revisit.

---

## Week 3 – Finish Domain 4, Domain 5, Heavy Practice

### Week 3 – General Goals

- [ ] Finish all Domain 4 material.
- [ ] Complete Domain 5 (governance, risk, compliance).
- [ ] Take 2–3 full practice exams and push scores into the 85–90%+ range.

---

### Week 3 – Mon–Tue (Finish Domain 4.0 – Security Operations)

Focus: IAM, NAC, DLP, EDR/XDR, email/DNS security, IR, forensics.

#### Tasks

- [ ] Read remaining Domain 4 sections in the Cert Guide:
  - [ ] IAM and provisioning / de‑provisioning.
  - [ ] Federation and SSO (LDAP, SAML, OAuth).
  - [ ] NAC, DLP, web filtering, email security (SPF, DKIM, DMARC).
  - [ ] EDR/XDR, UBA, file integrity monitoring.
  - [ ] Incident response process and basic forensics concepts.
- [ ] Watch Messer videos:
  - [ ] IAM, SSO, MFA, PAM.
  - [ ] NAC, DLP, email/DNS/web security controls.
  - [ ] SIEM, log sources, IR workflow, forensics basics.
- [ ] Questions:
  - [ ] 60–80 Domain 4 questions per day.
  - [ ] Aim for ≥80% on Domain 4‑focused sets.

---

### Week 3 – Wed–Thu (Domain 5.0 – Security Program Management & Oversight)

Focus: governance, risk, third‑party, compliance, audits, awareness.

#### Tasks

- [ ] Read Cert Guide chapters for Domain 5.0:
  - [ ] Policies, standards, procedures, guidelines.
  - [ ] Governance structures and roles (owners, controllers, processors, custodians).
  - [ ] Risk management (qualitative/quantitative, SLE/ALE/ARO, risk responses).
  - [ ] Third‑party risk (vendor selection, SLAs, NDAs, right to audit).
  - [ ] Compliance and consequences, privacy concepts.
  - [ ] Audits, assessments, pen test types, rules of engagement.
  - [ ] Security awareness practices and training.
- [ ] Watch Messer Domain 5 videos:
  - [ ] Governance and policy.
  - [ ] Risk management and business impact analysis.
  - [ ] Third‑party risk and contracts.
  - [ ] Compliance, audits, awareness training.
- [ ] Questions:
  - [ ] 40–50 Domain 5 questions per day.
  - [ ] 20 mixed questions from earlier domains.

---

### Week 3 – Fri–Sun (Full‑Exam Mode & Deep Review)

#### Tasks

- [ ] Full practice exams:
  - [ ] Take 2–3 timed 90‑question exams (alternate LogN Pacific and FlashGenius).
  - [ ] After each exam, list incorrect questions by domain and sub‑objective (using the official objectives PDF).
- [ ] Targeted review:
  - [ ] Re‑read specific Cert Guide sections for any repeatedly missed objective.
  - [ ] Re‑watch only the relevant Messer segments for weak topics.
- [ ] Success criteria:
  - [ ] ≥85–90% on at least two different full practice exams.
  - [ ] Missed questions spread across domains (no single glaring weak domain).

---

## Week 4 – Optional Buffer / Final Polish

Use this week if your scores are inconsistent or you want extra confidence before scheduling.

### Week 4 – Day 1–2 (Objectives + Flashcards)

- [ ] Walk the CompTIA exam objectives PDF line‑by‑line:
  - [ ] Confirm you can explain every bullet in 1–2 sentences.
  - [ ] Mark any bullet you cannot explain quickly for targeted review.
- [ ] Hit flashcards:
  - [ ] Drill the LogN Pacific Anki deck for acronyms and definitions.
  - [ ] Focus on ports, protocols, IAM models, crypto concepts, and risk formulas.

### Week 4 – Day 3–4 (Final Timed Exams)

- [ ] Take two more full‑length timed exams:
  - [ ] Exam 1: score + full review.
  - [ ] Exam 2: score + review; confirm 85–90%+.
- [ ] Patch final weak spots:
  - [ ] Re‑read and re‑watch only the topics still causing misses.

### Week 4 – Day 5 (Pre‑Exam Day)

- [ ] No heavy study.
- [ ] Light skim of:
  - [ ] Your own notes/summaries.
  - [ ] Marked tricky concepts.
  - [ ] Acronyms and key formulas (SLE, ALE, ARO, RTO, RPO, etc.).
- [ ] Confirm logistics:
  - [ ] Exam scheduled via CompTIA or testing provider site.
  - [ ] ID, testing center/online setup, time, and environment are all ready.
- [ ] Sleep, hydrate, and don’t change your routine.

---

## Ongoing Habits (All Weeks)

- [ ] Track daily progress by checking off tasks in this note.
- [ ] Maintain a “High‑risk weak topics” section at the top of your vault’s Security+ index note.
- [ ] After each question session:
  - [ ] Add any repeatedly missed topic to the weak‑topics list.
  - [ ] Plan the next day’s study around those items.
